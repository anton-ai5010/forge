# Звуки

Запасные звуки уведомлений. С v7.14.0 основной — живой голос (`voice/`: «<проект>: что случилось»); эти mp3 играют, если голос не установлен (`voice/install.sh`), сломался, выключен не командой, а поломкой, или система не macOS. Каждый раз выбирается случайный файл из нужной папки. Три записи VASKO из `stop/` (`*12_04_34*`, `*12_04_52*`, `*12_05_08*`) — образец, по которому собран голос: не удалять и не переименовывать.

## stop/

Голоса завершения — звучат когда Клод заканчивает отвечать, чтобы не надо было смотреть на экран в ожидании.

- **ElevenLabs_..._Roger_....mp3** — голос Roger (расслабленный, разговорный) — уведомление о завершении
- **ElevenLabs_..._VASKO_...mp3** (6 файлов) — голос VASKO (глубокий, тёплый) — варианты уведомления о завершении с разными параметрами синтеза
