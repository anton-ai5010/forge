# Глубина размышлений по фазам

Пункт 2.5 очереди, решение DEC-22. Антон 2026-10-23: «пусть думает сколько нужно» → понял, что глубина — потолок, а не таймер; выбрал вариант «глубоко там, где решается что делать» (не максимум везде: xhigh в 2–3 раза дороже high, поправок не меньше — разбор чатов в DEC-22).

## Задача
Глубина размышлений ставится сама по фазе, без «напиши /effort …» от владельца: план думает глубже обычного (xhigh), разбор задачи и критика — на обычном high, реализация — глубину, которую критика вписала в план. Если чат уже на нужном уровне, Claude не просит ничего переключать.

## Критерий готовности
- Запуск плана в новом чате идёт на уровне xhigh без команды владельца — видно по записи чата, на каком уровне шли ответы.
- Уровень плана держится дальше первого ответа, на всех ходах фазы; если Claude Code сбрасывает его после первого ответа — это выяснено замером и честно написано в отчёте вместе с обходным путём.
- В скиллах new-task, refine-idea, plan, critique больше нет просьбы «напиши `/effort high`».
- Critique вписывает в Execution Strategy строку «глубина реализации: …» (обычно high, для денег / прода / удаления данных — выше); execute подсказывает именно её, а не всегда «хватит medium».
- Тесты плагина зелёные.

## Доработано на разборе
- Главная польза — убрать просьбы «напиши `/effort high`» (new-task, refine-idea, plan, critique: high уже по умолчанию, ~/.claude/settings.json) и совет execute «хватит medium» (противоречит DEC-22). Делается первым, ценно и без остального.
- Первый шаг плана — живая проверка: держится ли `effort: xhigh` из frontmatter plan на ходах после первого. Не держится — план остаётся на high, честно в отчёте, без обходных механизмов (план — ~45 ходов за 3 месяца, игра не стоит свеч).
