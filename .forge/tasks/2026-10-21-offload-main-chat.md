# Разгрузка основного чата

## Задача
Разгрузить основной чат, в котором владелец сидит подолгу: Claude во всех проектах сам отдаёт помощникам работу, которая принесла бы в чат много материала (файл на сотни строк, несколько файлов, длинный вывод команд и тестов, поиск в интернете), и сам выбирает помощнику модель и effort по таблице ролей (`forge-plugin/docs/model-roles.md`); короткое делает сам — помощник стартует с нуля и стоит заметно дороже самого материала. Помощники отвечают коротко, подробности пишут в файл. Действует везде, а не только в execute: в обычном разговоре, разборе идеи, плане, критике, проверке кода, расследовании. О каждом поручении в чате — одна строка «отдал помощнику (Haiku): найти, где вызывается X», потом короткий итог.

## Критерий готовности
- При старте каждого чата есть правило: когда отдавать помощнику (граница по объёму материала), когда проще самому (одна короткая команда, один небольшой файл), какую модель и effort брать по таблице ролей.
- Разбор идеи, план, критика, проверка кода, расследование и обычный разговор ссылаются на это правило (не только execute).
- Ответ помощника в основной чат — короткий итог (до ~20–30 строк) со ссылками «файл:строка»; подробности (полные отчёты критиков, проверяющих) — в `.forge/notes/<slug>.md`; главное основной чат перепроверяет точечно.
- В чате при каждом поручении — одна строка «отдал помощнику (<модель>): <что>», затем итог.
- Живая проверка: в новом чате на вопрос вида «как устроен рендерер гайда» Claude отдаёт чтение помощнику, а не читает файл на 1000 строк сам; строка про помощника видна, у помощника явная модель; на вопрос про один короткий файл — читает сам.
- Замер до/после на этом же вопросе — две цифры: память основного чата и общий расход (чат + помощники); в отчёте обе.
- Тесты плагина зелёные.

## Доработано на разборе
- Граница «отдавать» — по объёму материала, а не «любое чтение»: помощник стартует с нуля (пересказ 18 КБ субтитров 2026-10-21 — ~57 тыс. токенов у помощника при ~6 тыс. самого текста), иначе чат чище, а лимит уходит быстрее.
- Короткие ответы помощников + подробности в notes: в сессии 2026-10-17..21 основной объём чата набрали полные отчёты критиков/проверяющих, а не файлы.
- Замер двумя цифрами (чат и общий расход), чтобы разгрузка не выглядела выгодной за счёт лимита.
