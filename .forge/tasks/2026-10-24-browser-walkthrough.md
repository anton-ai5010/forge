# Прокликай в браузере

Антон 2026-10-21 согласовал «добавим в проверку запуск в браузере и клики» (направление «Проверяющий в браузере», образец — агент-тестер из ролика AshyGray про VibeForge). 2026-10-24 на постановке передумал: проход в каждой проверке — лишний расход; нужен отдельный навык для некоторых случаев. Опирается на one-chrome (DEC-27): своё — невидимый Playwright, живые сайты — Chrome владельца.

## Задача
Отдельный навык «прокликай в браузере»: Claude проходит веб-страницу как пользователь — открывает, нажимает, заполняет по пути из критерия готовности; найденное чинит и проходит заново; владельцу — строка и 3–5 снимков на одной страничке. Сам не запускается — в конце задачи с веб-страницей только подсказывает одной строкой.

## Критерий готовности
- На «прокликай» / «проверь в браузере» / «пройди как пользователь» Claude проходит путь из критерия готовности текущей задачи (нет задачи — то, что назвал владелец).
- Итог в чате: строка «прошёл в браузере: …» + ссылка на одну страничку с 3–5 снимками (открывается кликом); при удалённом доступе — тот же файл присылается.
- Сломанное на проходе (кнопка не работает, ошибка, пустая страница) Claude чинит и проходит заново; «готово» с неработающей страницей не говорит.
- Своё (localhost, локальные страницы) — невидимый Playwright, проходит помощник, окон нет; живой сайт — Chrome владельца, проходит только основной чат: нажимать можно всё, кроме оплаты / отправки от имени владельца / удаления — перед ними «Стоп: …? да/нет»; тестовые записи, созданные на живом сайте, перечислены в итоге.
- В финальном отчёте задачи, менявшей веб-страницу, строка «прогнать в браузере? скажи „прокликай“»; в задачах без веб-страниц её нет.
- Без этих слов навык не запускается — ни в проверке шагов, ни в конце задачи.

## Доработано на разборе
- Живой сайт — только основной чат (DEC-27: помощники в Chrome только читают); своё — помощник в невидимом Playwright, чтобы не засорять чат.
- Снимки — одной страничкой со ссылкой (в VS Code и через удалённый доступ картинки из чата владельцу видны не всегда).
- Запуск проекта не изобретать: опереться на встроенный навык Claude Code «run» (что он умеет — проверить в плане); наш навык добавляет путь из критерия, правила живого сайта, починку с повтором, отчёт.
