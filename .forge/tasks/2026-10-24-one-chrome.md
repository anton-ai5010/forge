# Один Chrome на все проекты

Антон 2026-10-24: Playwright MCP в каждом чате открывает свой отдельный Chrome — бесит; хочет один Chrome с многими вкладками. Сегодня Claude in Chrome спрашивал разрешение ~10 раз.

Найдено при разборе: Claude in Chrome включён (`~/.claude.json`: claudeInChromeDefaultEnabled), но `mcp__claude-in-chrome__*` нет в allow `~/.claude/settings.json` → вопрос на каждое действие. Плагин `playwright@claude-plugins-official` включён глобально → его инструменты есть в каждом чате (DEC-25: ~3800 вызовов Playwright за 50 чатов, в том числе у помощников). Playwright упоминается в скиллах плагина: project-guide (снимки экранов), systematic-debugging, code-cleanup, project-unblocker, forge-context, subagent-driven-development, security-review, commands/sync.md. 34 проекта в ~/.claude/projects, не во всех есть .forge.

## Задача
Все Claude во всех проектах работают с сайтами в Chrome владельца через Claude in Chrome — каждый в своих вкладках, без отдельных окон Chrome. Playwright остаётся только невидимым (без окна) — для проверки своего: свои страницы, снимки, тесты. Обычные действия в браузере — без вопросов, перед необратимыми — вопрос; входы — из залогиненного Chrome владельца и Bitwarden в Chrome, пароли никуда не пишутся. Правило и разрешения — в общих настройках владельца (действуют во всех проектах), плагин им следует.

## Критерий готовности
- В новом чате любого проекта на «открой сайт X» появляется вкладка в Chrome владельца — нового окна Chrome нет, вопроса разрешения нет.
- Два чата из разных проектов одновременно работают в одном Chrome, каждый в своих вкладках, не сбивают друг друга (проверено живьём; не держит — честно в отчёте с обходом).
- Открыть / прочитать / нажать / заполнить — молча; перед оплатой, отправкой сообщения или письма от имени владельца и удалением на сайте — Claude спрашивает.
- Сайт, где владелец уже вошёл, открывается сразу; где не вошёл — Claude входит сам через автозаполнение Bitwarden, код из СМС / капчу просит у владельца; пароля нет ни в чате, ни в коде, ни в `.forge`.
- Playwright ни в одном чате и ни у одного помощника не открывает видимое окно Chrome; проверки своих страниц, снимки для гайда и тесты идут через него невидимо.
- Свои вкладки Claude не закрывает (владелец закрывает сам).
- Если Chrome закрыт / расширение не отвечает, а нужен сайт с входом или то, на что смотрит владелец — Claude одной строкой «открой Chrome», а не тихо Playwright.

## Доработано на разборе
- «Playwright только в тестах» → «Playwright только невидимый»: бесят окна, а не Playwright; помощники (снимки, проверка своих страниц) не толкаются в видимом Chrome владельца. Делёж: интернет-сайты / вход / то, что смотрит владелец — его Chrome; проверка своего — невидимый Playwright.
- Первый шаг плана — живая проверка, держит ли Claude in Chrome несколько чатов одновременно.
- Правило и разрешения — в общих настройках (~/.claude), не только в плагине: 34 проекта, не все с .forge.
