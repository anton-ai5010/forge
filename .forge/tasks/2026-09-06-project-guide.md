# Гайд по проекту — фаза 5 становится живым версионным документом (project-guide)

## Задача
Переделать фазу 5 так, чтобы вместо списка «Что дальше» она вела **гайд по проекту** в духе «Vespera — гайд по продукту и решения на утверждение»: один живой документ, из которого человек со стороны понимает проект целиком (суть, устройство, экраны, роли, принятые и открытые решения с кодами, риски, план). Каждый запуск не пишет с нуля, а **дополняет и правит** прошлую версию; все версии хранятся в папке проекта, номер версии отражает состояние проекта (1.0 → 1.1 → 1.2 → 2.0).

Эталон: `/Users/mac/Downloads/Telegram Desktop/Vespera-гайд-и-решения.pdf` (17 стр.), исходник `/Users/mac/Projects/project vlad/konsierg/docs/vespera-guide-src.html`; копия исходника без картинок приложена: `.forge/tasks/2026-09-06-project-guide/reference-vespera-guide.html`.

## Критерий готовности
- «Собери гайд» → в папке `docs/guide/` появляется `guide-v1.0.html` (и PDF той же версии), открывается в браузере. Внутри по порядку: шапка с версией и датой · 00 «где мы — за 30 секунд» + 🔥 «без чего стоим» + «как работать с документом» · 01 суть одной схемой + экраны · 02 из чего состоит · 03 главный путь по шагам · 04 роли · 05 решения с кодами и «почему» (принятые, предложения-«дефолт», открытые) · 06 карта рисков с «предлагаем» · 07 план «сейчас → дальше → позже» · 08 словарик · футер «откуда собрано».
- Повторный запуск находит прошлую версию и меняет только изменившееся: сделанное уходит в «работает»/«принято», новое добавляется, устаревшее убирается; номер растёт на 0.1; «это версия 2» → 2.0. Все версии остаются в папке, `guide-latest.html` — копия последней.
- Ответы кодами в чате («A2 — ок, B2 — переделать: …, D2 — обсудить») меняют реестр: A2 → принято, B2 → текст переписан, D2 → «обсудить»; следующая версия это отражает, в 🔥 остаются только неотвеченные.
- Экраны: есть веб-интерфейс → настоящие снимки с подписями; бот в Telegram → нарисованный диалог из настоящих текстов бота с подписью «воспроизведение, данные вымышленные»; показывать нечего → без картинок и без вопросов.
- Язык — для читающего со стороны, на «вы», без жаргона; в шапке видно, для кого документ и какая версия проекта.
- Всё, что фаза 5 уже умеет, сохраняется: после мержа сделанная задача отмечается сама, при старте сессии напоминание «ждут N решений», «открой гайд» — без пересборки.
- Старый формат «Что дальше» больше не собирается; документация плагина описывает гайд; версия 7.8.0 на GitHub.

## Решения, принятые Клодом (владелец может отменить)
- Внешний вид — как у гайда (тёплая палитра, шрифты Playfair + Golos, печать на A4), а не как у «Что дальше».
- Папка версий — `docs/guide/` в корне проекта, на виду, а не в скрытой `.forge`.
- Группы кодов: P (процесс), O (открытые), R (риски) — всегда; остальные буквы Клод подбирает под проект (как A/B/C/D у Vespera).
- PDF делается через Chrome на маке владельца (есть, версия 152); нет Chrome — только HTML.
- Один документ вместо двух: «что чинить / что решать» живёт внутри гайда (🔥, решения, риски, план) — выбор владельца.

## Доработано на разборе
- Разделы «как устроено» (суть одной схемой, из чего состоит, путь по шагам, роли) собираются механизмом карты проекта (product-mapping: bigPicture / flows / entities / gaps), принятые решения — из памяти решений проекта; аналитики фазы 5 остаются на рисках, плане и открытых вопросах. Не изобретаем второй извлекатель устройства проекта.
- Файл данных отчёта (`.forge/status-report.json`, находки с owner/status/task_slug) остаётся скелетом гайда — слоем рисков и плана; новые разделы наращиваются вокруг него. Так не ломаются обновление после мержа, напоминание при старте сессии, связь карточки с задачей и существующие тесты.
- Версии: данные каждой версии — в памяти проекта (`.forge/guide/`, сохраняются автоматически), видимые HTML + PDF — в `docs/guide/`; сохранение памяти дополняется одной строкой, чтобы `docs/guide/` тоже уезжал на GitHub. Иначе история гайда умрёт вместе с диском.
- Нарисованные диалоги Telegram — только когда тексты бота находятся в коде; иначе без них, без вопросов. PDF — через Chrome (на маке есть, 152).
