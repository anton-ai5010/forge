# Голосовые уведомления: какой проект и что случилось

## Задача
Заменить звуки-заготовки (mp3 на Stop / PermissionRequest) на живой бесплатный офлайн-голос, который говорит, **в каком проекте** что случилось — нужно разрешение или готов ответ (и одной фразой, что сделано). Чтобы при 4 рабочих столах × 3–4 проекта (VS Code + Claude в каждом) сразу понимать, куда идти.

## Критерий готовности
- Запрос разрешения → голос всегда, где бы ты ни был: «Дом: жду разрешения — хочу запустить команду».
- Ответ готов, а окно этого проекта не перед тобой (спрятано за другим окном, на другом рабочем столе, впереди браузер) → голос: название проекта + что сделано одной фразой ≤ 5 секунд («Интеграция: проанализировал поставщиков»).
- Ответ кончается вопросом к тебе → «Плагин: есть вопрос к тебе».
- Промежуточный ответ (жду фоновый прогон/проверку, плановый обход «тихо», «продолжаю») → начинается со значка ⏳ и голос молчит; итог / новость («поддержка подтвердила возврат», «тесты прошли») — без значка и озвучивается. Сомнение — без значка (лучше лишний голос, чем пропущенная новость).
- Ответ готов в переднем проекте, и ты за компьютером → тишина.
- Ты больше минуты не трогал мышь/клавиатуру → говорит даже передний проект.
- Без «Универсального доступа» (разрешение macOS) → говорит после каждого ответа + строка об этом в начале чата (поправлено на критике: проще и надёжнее, доступ у владельца уже есть).
- «Выключи голос» / «включи голос» в любом чате → полная тишина (ни голоса, ни mp3) / снова говорит.
- Голос сломался → играют mp3, раз в 3 часа системный голос: «голос сломался — скажи „почини голос“», строка в начале чата; «почини голос» — Клод разбирается сам.
- Серия ⏳-ответов, затем итог («тесты прошли») → итог озвучен; «тихо» / «ничего нового» без значка → тоже молчит.
- Задержка: разрешение / «есть вопрос» / «готово» — сразу (заготовлены заранее); «что сделано» — 15–25 с после ответа, фраза до 6 слов.
- Названия проектов — по-русски, как их называет владелец (плагин, дом, психология, консьерж, интеграция); поменять — фразой «называй этот проект …».
- Два проекта закончили одновременно → фразы по очереди, не поверх друг друга.
- Голос выбран владельцем на слух из 2–3 вариантов; короткая фраза не тратит недельный лимит.
- Голос не установлен / сломался → играют старые mp3, ничего не ломается.

## Контекст (найдено при разборе)
- Сейчас: `forge-plugin/hooks/hooks.json` — Stop и PermissionRequest играют случайный mp3 из `sounds/stop|permission/` через `afplay -v 0.05` (async), молчат при `FORGE_NESTED`.
- Мак: arm64, macOS 26.6, Python 3.14, Claude Code 2.1.309, Ollama есть (`/opt/homebrew/bin/ollama`); piper/torch не стоят. Встроенный русский голос — только Milena (роботизированная).
- Проверено вживую: передняя программа — `lsappinfo front` без разрешений («Code»); простой мыши/клавиатуры — `ioreg -c IOHIDSystem` HIDIdleTime без разрешений; заголовок переднего окна через System Events → ошибка -1719 (нужен «Универсальный доступ»).
- Папки проектов латиницей и с дублями (`Ya. Market/integration`, `integration-strike`, `-ns`, `-lcc`, `-cleanup`; `Trading/mexc`, `mexc2`), «консьерж» — не имя папки → нужна таблица произносимых имён.
- DEC-20: «под друга не делаем, всё под меня» — достаточно macOS; у остальных пользователей плагина без голоса — mp3 как раньше.

## Доработано на разборе
- Готовые голосовые хуки (claude_voice, claude-code-voice-hook) — без названия проекта, правила «переднее окно молчит» и русского → свой маленький хук, идею берём у них.
- Фраза «что сделано» — первая фраза ответа (по Forge Concise она и есть «что сделал»), очищенная от путей/кода, ≤ 8–10 слов; без отдельной нейросети (Ollama-модели на маке 16–23 ГБ, холодный старт > 60 с). Маленькая быстрая модель — только если фразы выйдут корявыми.
- Порядок: план + критика сейчас, код — сразу после friend-report-fixes (там же правка громкости 0.12→0.05 в `hooks.json`), раньше offload-main-chat. Голоса пробуем на слух до плана — проба в scratchpad, не код плагина.
- С пунктом очереди «Atoll/Chimlo» не конфликтует — дополняет (там видно, тут слышно).
- **Голос выбран на слух (DEC-21):** локальная копия VASKO через Chatterbox Multilingual (по образцу из 3 mp3 `sounds/stop/*VASKO*sp100*`), ударения russian_text_stresser, «на 10% медленнее и ниже». Отпали: Silero (4 голоса — «дичь»), Chatterbox по умолчанию, ElevenLabs по API (≈200 фраз/день → $22–99/мес, потолок владельца $5), Яндекс (платный). Piper не завёлся на маке.
- **Скорость:** 12.5 с на фразу 60 символов (M5 Pro, MPS) + ~9 с загрузки модели → постоянные фразы (проект + «жду разрешения» / «есть вопрос» / «готово») делаются заранее и играют из файла мгновенно; живая генерация — только «что сделано», с задержкой (владелец в этот момент не у окна). Критерий «≤ 5 с» — это длина фразы, не задержка.
- **Рецепт пробы** (scratchpad, пересоздать в постоянном месте): `uv venv --python 3.11` + `chatterbox-tts` + `git+https://github.com/Vuizur/add-stress-to-epub`; `perth.PerthImplicitWatermarker = perth.DummyWatermarker`; `generate(..., language_id="ru", audio_prompt_path=vasko.wav, cfg_weight=0.3, exaggeration=0.4)`; ffmpeg `asetrate=22080,aresample=24000,atempo=0.9783`. Подводные камни — learnings `local-tts-macos-pitfalls`.
