## Отклонения
- Шаги 1–2: планировали помощников Sonnet → вписал тексты сам → тексты были готовы в плане целиком, помощники перечитывали бы те же файлы.
- Чекпоинт A, по слову владельца («лучший код — тот, который не написан, всегда искать готовые библиотеки»): в лесенку добавлена ступень 7 «готовая проверенная библиотека, которую можно поставить» (для заметного куска; живая, популярная, лицензия; через чекпоинт) и девиз первой строкой; пункт 8 чеклиста — «для заметного куска — известная живая библиотека». Ступеней стало 8.
- Шаг 4, по проверке (4 Sonnet-угла, Codex выключен в проекте): буква упрощений не жёстко S — в проекте strip гайд уже держит свою группу S1–S3 (коды менять нельзя) → S или первая свободная из SUZYXWVQ, запоминается в meta.shortcut_letter, упрощения узнаются по shortcut_key, а не по букве. Сбор снимает только «дефолт» без задачи («обсудить» больше не теряется при смене ветки). git grep -z (двоеточие в имени файла) + --untracked (новые файлы); заголовок ≤80 символов, what пустой, если совпадает с заголовком; тексты журнала «упрощение убрано из кода / снова в коде (заголовок)»; фраза в «как работать» — «ответа не требуют … «S2 в работу» / «S2 обсудить»» (без «переделать» — в гайде это другое действие); «где:» — переносится на узком экране. Строка «где:» — отдельной строкой карточки, а не в «Почему» (у обычных решений source — «откуда взято»).
- Шаг 4: строка «где:» выводится только у упрощений (по shortcut_key) — поле source у прочих решений уже значит «откуда взято».
- Проверка кода: дифф передан проверяющим файлом, а не вставкой в промпт (307 строк × 4).
