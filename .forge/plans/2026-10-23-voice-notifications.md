# План: Голосовые уведомления — какой проект и что случилось

**Задача:** см. `.forge/tasks/2026-10-23-voice-notifications.md` (голос — DEC-21: локальная копия VASKO через Chatterbox).

**Подход:** Хуки Stop и PermissionRequest вместо mp3 зовут маленький `voice/notify.py` (только stdlib): он решает «говорить или молчать» (⏳ и тихие слова, переднее окно, простой мыши, «выключи голос»), собирает фразу «<проект>: <что>» и кладёт её в очередь. Отдельный фоновый `voice/voiced.py` держит модель в памяти, берёт фразы по приоритету (разрешения первыми), озвучивает голосом VASKO (постоянные фразы — заранее, в простое) и играет по одной. Нет голоса / сбой — старые mp3, а поломка видна и слышна.

**Что увидишь ты:**
- Голос VASKO называет проект и что там: «Дом: жду разрешения — хочу запустить команду», «Интеграция: проанализировал поставщиков», «Плагин: есть вопрос к тебе». Разрешения — всегда; ответы — только если проект не перед тобой или ты больше минуты не трогал мышь/клавиатуру.
- Промежуточные ответы во всех проектах начинаются со значка ⏳ («⏳ Обход 12:07 — тихо», «⏳ Жду результатов тестов») — голос на них молчит; на «тихо», «ничего нового» молчит, даже если чат забыл значок.
- Задержка: «что сделано» звучит через 15–25 секунд после ответа (голос делается на маке), до 6 слов. Разрешения, «есть вопрос», «готово» — готовые записи на все проекты, звучат сразу (заготовка — один раз ~25 минут в фоне после установки).
- «Выключи голос» / «включи голос» в любом чате — полная тишина на созвон/ночь и обратно.
- Голос сломался — играют старые mp3, раз в 3 часа системный голос скажет «голос сломался — скажи „почини голос“», и строка об этом в начале чата; чинит Клод.
- «Универсальный доступ» у VS Code уже есть (проверено 2026-10-23: заголовок переднего окна читается — «Браузерная автоматизация… — plugin», разделитель « — », имя папки — отдельный кусок). Пропадёт — голос говорит после каждого ответа, и строка об этом в начале чата.
- Голос держит ~3 ГБ памяти, пока мак включён (у тебя 48 ГБ — владелец: «не дофига»). Таблицу названий проектов (~45 папок) покажу на паузе A — поправишь. Handy на маке — только распознавание речи, озвучки в нём нет.

**Открытые вопросы:** нет (громкость подбираем на паузе B).

**Блокеры:** нет. Порядок: код — после мержа friend-report-fixes (та ветка трогает `hooks.json`, `session-start.sh` + тест и `output-styles/forge-concise.md` — правило «понял так»). Версия — 7.14.0; offload-main-chat сдвигается на 7.15.0.

**Общее для всех шагов:** домашняя папка голоса `VOICE_HOME = $FORGE_VOICE_HOME or ~/.claude/forge-voice` (вне репо, как `forge-logs`). Корень проекта — `$CLAUDE_PROJECT_DIR`, иначе `cwd` из входа хука. Подмены для тестов: `FORGE_VOICE_FRONT=1|0|unknown`, `FORGE_VOICE_IDLE=<сек>`, `FORGE_VOICE_DRYRUN=1` (печатает `silent` / `mp3 <kind>` / `say <фраза>` вместо действия), `FORGE_VOICE_ENGINE=fake`, `FORGE_VOICE_PLAYER=log:<файл>`.

## Шаг 2: `voice/notify.py` — решение и фраза (TDD)

**Файлы:**
- Создать: `forge-plugin/voice/notify.py` (stdlib, системный `python3`)
- Создать: `forge-plugin/tests/hooks/test-voice-notify.sh` + `forge-plugin/tests/hooks/fixtures/voice/*.json`

**Что делаем:** вход — `notify.py stop|permission` + JSON на stdin; команды `notify.py name [<имя>]` (без имени — печатает имя текущего проекта; с именем — записывает в `names.json`), `notify.py mute|unmute` (флаг `VOICE_HOME/mute`). Весь `main()` — в `try/except`: любая ошибка → mp3 нужного вида + строка в `VOICE_HOME/voiced.log` (сейчас хук хотя бы пищит — хуже не делаем).

```python
QUIET = ("тихо", "ничего нового", "без изменений", "новых сообщений нет")

def strip_intro(text):                      # «понял так: …» первой строкой — пропустить (правило стиля)
    lines = [l for l in text.strip().splitlines() if l.strip()]
    if lines and lines[0].lstrip("*_#> ").lower().startswith("понял так"):
        lines = lines[1:]
    return "\n".join(lines)

def decide_stop(body, front, idle):
    if body.lstrip("*_#> \n").startswith("⏳"):
        return False
    if any(w in first_sentence(clean_md(body)).lower() for w in QUIET):
        return False
    if front is None:                       # нет «Универсального доступа» → говорим всегда
        return True
    return (not front) or idle > 60

def front_project(root):                    # True / False / None — не знаем
    if 'LSDisplayName"="Code"' not in sh("lsappinfo info -only name $(lsappinfo front)"):
        return False                        # впереди не VS Code
    title = osascript('tell application "System Events" to tell process "Code" to get name of front window')
    if title is None:                       # -1719: нет доступа → метка VOICE_HOME/no-access
        return None
    return basename(root) in title.split(" — ")

def idle_seconds():                         # ioreg -c IOHIDSystem → HIDIdleTime / 1e9

ACTIONS = {"Bash": "хочу запустить команду", "Edit": "хочу изменить файл", "Write": "хочу изменить файл",
           "MultiEdit": "хочу изменить файл", "NotebookEdit": "хочу изменить файл",
           "WebFetch": "хочу в интернет", "WebSearch": "хочу в интернет"}

def permission_phrase(name, tool):
    act = ACTIONS.get(tool)
    return f"{name}: жду разрешения — {act}" if act else f"{name}: жду разрешения"

def stop_phrase(name, body):
    lines = [l for l in body.splitlines() if l.strip()]
    if not lines:
        return f"{name}: готово"
    if lines[-1].rstrip().endswith("?"):
        return f"{name}: есть вопрос к тебе"
    s = first_sentence(clean_md(body))      # без ```блоков```, `кода`, [текст](ссылка)→текст, путей, **, эмодзи
    s = " ".join(s.split()[:6])[:45]
    return f"{name}: {s}" if s else f"{name}: готово"
```

- Текст ответа — `last_assistant_message`, иначе последний ответ из `transcript_path`; пусто → «<имя>: готово».
- Имя проекта — точное совпадение корня проекта в `names.json` (`{"<абсолютный путь>": "имя"}`), иначе транслит имени папки латиница→кириллица.
- `mute` → полная тишина (ни голоса, ни mp3).
- Голос не установлен (`VOICE_HOME/venv/bin/python` нет) или не macOS → случайный mp3 из `sounds/<kind>/` как сейчас (`afplay -v 0.05` / `paplay --volume 3277`).
- Установлен → задание `VOICE_HOME/queue/<время>-<pid>.json` `{text, kind, project, fixed, created, mp3_dir}` (запись во временный файл + `os.rename`). `fixed` = фраза из постоянного набора (разрешения, «есть вопрос», «готово»).
- Жив ли демон — по `flock` на `VOICE_HOME/voiced.lock` (взялся без ожидания → демона нет). Нет → запустить `venv/bin/python <своя папка>/voiced.py` отвязанно (`start_new_session=True`, вывод в `voiced.log`).
- В `voiced.pid` демон пишет `pid путь_к_voiced.py`; путь не совпал со своим (плагин обновился) → `VOICE_HOME/restart` + запуск нового демона (он ждёт `flock`, пока старый доиграет и выйдет).
- Демон завис: старейшее задание старше 60 с, а `voiced.beat` старше 30 с → mp3 + метка `VOICE_HOME/broken` («завис»). Есть свежая (< 10 мин) `broken` → не перезапускать, mp3. При mp3 из-за поломки — раз в 3 часа (`VOICE_HOME/warned`) Milena: `say -v Milena -o <tmp>.aiff "Голос сломался, скажи: почини голос"` → `afplay -v`.

**Как проверим:** `bash forge-plugin/tests/hooks/test-voice-notify.sh` — сначала красный, потом зелёный. Случаи: ⏳ → silent; `**⏳` → silent; «понял так: …» + ⏳ второй строкой → silent; «Обход 12:07 — тихо» без значка → silent; «Поддержка маркета подтвердила возврат» при не переднем → say; серия: ⏳-ответ silent, следом итог «Тесты прошли» → say; переднее + активен → silent; переднее + простой 120 с → say; unknown → say; первая фраза вычищена (пути/ссылки/код) и ≤ 6 слов / 45 символов; «понял так» не попадает во фразу; последняя строка с «?» → «есть вопрос к тебе»; пустой текст и `{}` на stdin → «готово» / mp3, без падения; permission Bash при переднем окне → «<имя>: жду разрешения — хочу запустить команду»; permission `mcp__x__y` → «<имя>: жду разрешения»; голоса нет → `mp3 stop`; mute → silent и без mp3; незнакомая папка `zombashnya` → «зомбашня»; `CLAUDE_PROJECT_DIR` = корень, `cwd` = подпапка, заголовок с корнем → silent; `name "Дом"` → записано, `name` без аргумента → «Дом»; живой демон с чужим путём в `voiced.pid` → `restart`.

## Шаг 5: `voice/voiced.py` — фоновый голос с очередью

**Файлы:**
- Создать: `forge-plugin/voice/voiced.py` (запускается из `VOICE_HOME/venv`; torch/chatterbox импортируются только внутри настоящего движка — fake работает на системном `python3`)
- Дополнить: `forge-plugin/tests/hooks/test-voice-notify.sh` — прогоны демона с `FORGE_VOICE_ENGINE=fake` и `FORGE_VOICE_PLAYER=log:<файл>`

**Что делаем:**
- Один экземпляр: `flock` на `voiced.lock` (ждёт, если держит старый); пишет `voiced.pid` (`pid путь`); каждые 5 с трогает `voiced.beat`; после каждого задания проверяет `restart` → выходит.
- Окружение: `HF_HUB_OFFLINE=1` (модель скачана установкой; без сети не висим). Загрузка модели упала → `broken` с причиной, выход.
- Модель — рецепт пробы: заглушка `perth.DummyWatermarker`, `map_location` под mps, `ChatterboxMultilingualTTS`, `cfg_weight=0.3`, `exaggeration=0.4`, образец `VOICE_HOME/ref/vasko.wav`. Ударения Chatterbox расставляет сам (`add_russian_stress` в токенизаторе), если стоит `russian_text_stresser`.
- Выбор задания: сначала `permission`, потом остальные; из нескольких не-разрешений одного проекта — только последнее (старые выбросить); старше 5 минут — выбросить; всё выброшенное — строкой в лог. Битое задание (не читается) — в лог и удалить, демон не падает.
- Фраза: цифры словами (`num2words`, ru) → `fixed` → кэш `VOICE_HOME/cache/<sha1(текст)>.wav`, нет — сгенерировать; живая — во временный файл, удалить после проигрывания. После генерации: ffmpeg `asetrate=22080,aresample=24000,atempo=0.9783`; длительность (`wave`) > 0.12 с × символы + 1 с → «бормотание»: одна повторная генерация, снова плохо → не кэшировать, вместо живой играть готовую «<имя>: готово», в лог.
- Играть `afplay -v VOLUME`, строго по одной. Ошибка генерации/игры → mp3 из `mp3_dir` задания + лог.
- В простое (очередь пуста): заготовить недостающие постоянные фразы для всех имён из `names.json` (×6: «жду разрешения», «— хочу запустить команду», «— хочу изменить файл», «— хочу в интернет», «есть вопрос к тебе», «готово»), по одной, с проверкой очереди между фразами.
- `упрощено: модель держится в памяти всё время (~3 ГБ) — выгружать по простою, если памяти станет мало`.

**Как проверим:** fake-движок: разрешение, пришедшее после двух stop, звучит первым; два stop одного проекта → звучит только последний; задание старше 5 мин → выброшено; повтор постоянной фразы → из кэша (генераций 1), живая фраза → в `cache/` нового файла нет; «длинный» клип → не в кэше, сыграно «готово»; `restart` → демон выходит после текущего; сбой загрузки → `broken`; сбой движка → mp3; второй экземпляр ждёт `flock`; заготовка в простое создаёт 6 файлов на имя.
