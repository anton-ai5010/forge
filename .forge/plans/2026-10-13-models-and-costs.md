# План: Модели и расходы — экономия недельного лимита без потери качества

**Задача:** см. `.forge/tasks/2026-10-13-models-and-costs.md` (Issue #54, цель «Экономия лимита»)

**Подход:** Один источник правды — таблица ролей `forge-plugin/docs/model-roles.md` (роль → модель + effort + потолок шагов + почему); скиллы ссылаются на неё как `$CLAUDE_PLUGIN_ROOT/docs/model-roles.md` (не на `docs/` проекта). Её реализуют: frontmatter типов помощников в `agents/` (model / effort / maxTurns), явный `model` в вызовах Agent внутри скиллов, обязательные `model`/`effort` у каждого `agent()` в воркфлоу (правило живёт в `execute` — там воркфлоу пишутся). Новая схема проверки кода (Sonnet-проверяющий с диффом + Codex другой семьи на medium-рассуждениях + пачечная проверка находок + Opus только для денег/прода/удаления/споров/деградации) живёт в `requesting-code-review`. Codex же — пятый критик «Скептик другой семьи» в `/forge:critique` (план + задача текстом, без доступа к проекту). До выпуска — сравнение качества на 2 старых проверках integration (условие выпуска); после — пилот на integration и замер. В окне пилота — блок документации по Прорабу (9 пунктов). Хвост (сжиматель логов, гигиена чата, подсказки effort) — после замера.

**Что увидишь ты:**
- Снаружи те же фазы и команды. Внутри критики, сборщики гайда и проверяющие идут на Sonnet/Haiku, Opus — только где думать трудно; Codex (подписка ChatGPT) — второй взгляд при проверке кода и пятый критик плана, лимит Claude не тратит.
- После проверки шага — по смыслу, без цифр: «проверка: чисто» или «проверка: нашла 2 проблемы — могло задвоить заказ; цена могла уйти ниже закупки — исправлено». Если Codex не сработал — так и сказано («проверял один Sonnet: Codex не ответил»), на важном шаге в этом случае сам зову Opus.
- Таблица «кто на какой модели» — одна страница с цветами (дешёвый / средний / дорогой), правится словами («критиков всех на Opus»).
- Перед выпуском — по каждой старой найденной ошибке одна фраза «что бы это значило в жизни» и значок «новая проверка нашла / не нашла». По ней решаешь «выпускаем».
- Память проекта аккуратнее: одна общая строка при старте сессии (гайд + «доки: N расхождений»), решения с кодами DEC-NN, большие файлы памяти грузятся оглавлением, «Не делать» не обрезается.
- В конце — «неделя ушла бы за N дней вместо M» и редкие подсказки по-человечески («чат разросся — дешевле продолжить в новом, сказать «передай»?»).

**Принцип исполнения — мера «по делу» (слово владельца 2026-10-13; в шаге 4.5 становится правилом плагина для всех проектов):**
- *Перебор — не делаем:* решение проблемы, которой не было; свой скрипт там, где хватает правила в тексте; флаги «на будущее»; общий механизм вокруг кода из одного места; обработка невозможного.
- *Нижняя планка — без неё шаг не сделан:* логика проверена тестом, который сначала падал; живой запуск с выводом команды; закрыты реальные риски (данные, секреты, деньги, прод); сбой виден, а не тихий; обработаны крайние случаи, реально встречающиеся в проекте; нет заглушек и TODO; не сделанное названо прямо.
- *Спорный случай:* «что сломается или кто пострадает, если этого не сделать?» Конкретный ответ из проекта — делаем полностью. «Ну мало ли» — не делаем, строкой в идеи.

**Автономный режим (ночью некому ответить):** пауза-чекпоинт без ответа ничего не блокирует навсегда, но ничего необратимого без «да» не делается никогда — выпуск версии, правка `~/.claude/settings.json`, включение Codex на проекте. Дойдя до паузы, Claude пишет `.forge/notes/waiting-for-owner.md` (что показать, что решить — один вопрос), делает только шаги, не зависящие от ответа, и первой строкой при следующем сообщении владельца: «дошёл до паузы X, жду тебя: <вопрос>».

**Открытые вопросы (на чекпоинтах, по одному, простыми словами):**
1. (A) «В других твоих проектах помощники, которым модель забыли указать, будут на Sonnet — дешевле, но чуть слабее на коде. Включить?» (`CLAUDE_CODE_SUBAGENT_MODEL=sonnet` в `~/.claude/settings.json`; плагин сам не может — только с «да», применяю через `update-config`.)
2. (A) «Включить строку внизу экрана, которая показывает расход недельного лимита? Без неё замер будет примерный, а подсказка про разросшийся чат не заработает.» (`statusLine` → `hooks/statusline.sh`.)
3. (C) «Codex видит только кусок изменённого кода (и, если ловушка шага 5 прошла, — больше ничего). Включаем его на integration?» Ответ → `codex_review: on` в `.forge/index.yml` integration + уточнение к `cost-plan-order` в decisions.

**Блокеры:** нет. Проверено: frontmatter помощника — `model` / `effort` / `maxTurns` (code.claude.com/docs/en/sub-agents; на `maxTurns` вывод помечается partial); Agent — `model` и `effort` в вызове; плагин не задаёт env (manifest-reference#settings); `codex-cli 0.160.1`, модель `gpt-6-astra`, effort из `~/.codex/config.toml` = high (переопределяем `-c model_reasoning_effort=medium`); на маке **нет `timeout`** (PyYAML поставлен 2026-10-13 для `/usr/bin/python3`), есть `perl`, `sandbox-exec`, `claude --bare`; Ollama есть; RTK нет; PostToolUse — `updatedToolOutput`; статуслайн — `rate_limits.seven_day.used_percentage`. ## Шаг 6: Схема проверки шага + правила воркфлоу

**Файлы:** `skills/requesting-code-review/SKILL.md` — раздел «Схема проверки шага» (заменяет «review after each batch» :80-92):
1. Вход: дифф шага + task-файл + критерий шага — в промпт.
2. Параллельно: `forge:code-reviewer` и `codex-review.sh review`.
3. Совпавшие находки — подтверждены; несовпавшие критичные — **один** проверяющий пачкой (sonnet), не по одному на находку.
4. Финальный Opus (`model: "opus"`, effort high) — если шаг `[важное]` (деньги/прод/удаление; запасной признак — пути/слова в диффе), **или** Sonnet и Codex разошлись по критичной, **или** проверяющий вернул partial (упёрся в потолок) — сначала один повтор, потом Opus, **или** Codex не сработал на `[важное]` (в ночном режиме — сам, днём — тоже сам, сообщив).
5. Исправление → повторная проверка только диффа фикса, тем же Sonnet.
6. Отчёт владельцу по смыслу: «проверка: чисто» / «нашла N — <фраза в жизни про каждую>, исправлено» / «не уложилась — позвал Opus»; деградация («Codex не ответил») — в той же строке; «Codex выключен/не установлен» — один раз за сессию. Подробности (кто что нашёл) — в `.forge/notes/`, не в чат.
